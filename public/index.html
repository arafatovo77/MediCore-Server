User Accounts

Accounts are stored on the server and passwords are hashed with bcrypt — never in plain text. Sign-in sessions use a token that expires after 8 hours. Roles decide what each person may change: Admin (everything, incl. users & settings), Receptionist (patients, appointments, billing, lab orders), Pharmacist (medicines & dispensing), Lab Technician (lab tests & results).

Data Export

Download a full export of all clinic data — patients, doctors, appointments, invoices, pharmacy stock, lab records and user accounts — as a single JSON file, for inspection or migration. An export is not a restorable backup: real backups are database backups (pg_dump), restored by whoever manages the server.

About MediCore

MediCore v2.1.0 — Server Edition: a clinic & hospital management system with user login and role-based access control. The first Admin account is created on first run. Clinic data is stored on the server in a database and reached through the MediCore API, so several counters can work with the same data. Figures are estimates for management use; always verify critical records.
